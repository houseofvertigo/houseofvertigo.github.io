# 🌀 คำเชิญไปดู Vertigo

เว็บหน้าเดียวสำหรับชวนคนไปดู **Vertigo (1958)** ที่ House Samyan รอบ 19:05 วันพฤหัสบดีที่ 20 สิงหาคม

ไม่มี build step ไม่มี dependency — เปิด `index.html` ก็ทำงานได้เลย

## ไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | ทั้งเว็บอยู่ในไฟล์นี้ไฟล์เดียว (HTML + CSS + JS) |
| `og.png` | รูป preview เวลาแปะลิงก์ลง LINE / X / Messenger |
| `.nojekyll` | บอก GitHub Pages ว่าไม่ต้องเอา Jekyll มายุ่ง |

## แก้ชื่อ / วัน / เวลา / โรง

แก้ที่ `CONFIG` บนสุดของ `<script>` ใน `index.html` จุดเดียว:

```js
const CONFIG = {
  her: 'เธอ',                            // ชื่อ/คำเรียกคนที่ถูกชวน
  me: 'เรา',                             // เรียกตัวเองว่าอะไร
  venue: 'House Samyan',
  when: '2026-08-20T19:05:00+07:00',     // ใช้คำนวณ countdown (เวลาไทย)
  whenLabel: 'พฤหัสบดี 20 สิงหาคม · 19:05',
  dodges: 5,                              // ปุ่ม "ไม่ไป" หนีกี่ครั้งก่อนยอมให้กด
};
```

ข้อความวัน/เวลาที่โชว์บนหน้าเว็บ (การ์ดหนัง, ตั๋ว, หน้าฉลอง) เป็น HTML ตรงๆ
ถ้าเปลี่ยนรอบ ให้ไล่แก้ในหน้า `index.html` ด้วย — ค้นคำว่า `19:05` เจอครบทุกจุด

ค่าเริ่มต้นเรียกอีกฝ่ายว่า "เธอ" ไม่มีชื่อจริงอยู่บนหน้าเว็บเลย
ถ้าอยากให้ขึ้นชื่อ ต่อท้าย URL ด้วย `?to=ชื่อ` เช่น `https://houseofvertigo.github.io/?to=มะลิ`
(ชื่อถูกใส่แบบ text ล้วน ยัด HTML เข้ามาไม่ได้)

## มีอะไรอยู่ในเว็บบ้าง

- เกลียวแบบโปสเตอร์ Saul Bass วาดด้วย SVG หมุนอยู่ข้างหลัง (หยุดเองถ้าเปิด reduce motion)
- countdown นับถอยหลังถึงเวลาฉาย
- ตั๋วปลอม 2 ใบ ที่โดนปั๊ม `CONFIRMED ✓` เมื่อกดตกลง
- ป้ายเรตติ้งกำมะลอ · รีวิวปลอมจากแม่กับเพื่อน · FAQ · สไลเดอร์ที่ลากลงยังไงก็เด้งกลับ 100%
- ปุ่ม "ไม่ไป" ที่วิ่งหนี 5 ครั้ง **แล้วยอมให้กดจริง** (ครั้งที่ 6 เข้าหน้า "ไม่เป็นไรน้า" ซึ่งเปลี่ยนใจกลับได้)
- กดตกลง → confetti + สั่งให้แคปหน้าจอไปทัก (เว็บไม่มี backend ไม่ส่งอะไรกลับ)
- คำตอบถูกจำไว้ใน `localStorage` เปิดซ้ำแล้วสถานะยังอยู่

## Deploy (GitHub Pages)

repo นี้ตั้งชื่อว่า `houseofvertigo.github.io` เพราะฉะนั้น GitHub Pages
จะเสิร์ฟ branch หลักที่ `https://houseofvertigo.github.io` ให้อัตโนมัติ ไม่ต้องตั้งค่าอะไรเพิ่ม
(ถ้ายังขึ้น 404 หลังจากรอสัก 2 นาที ไปที่ Settings → Pages → Branch: `main` → Save)

## เทสต์

```bash
python3 -m http.server 8099      # แล้วเปิด http://127.0.0.1:8099
```
